# News
# 📰 Daily News

Daily News is a modern English news website designed with a clean,
calm and responsive interface.

The project covers different news categories including Politics,
Economy, Sports, Movies, Technology, World News, Health and Entertainment.

---

## Features

- Latest News
- Breaking News
- Politics
- Economy
- Sports
- Movies
- Technology
- World News
- Health
- Entertainment
- Category Filtering
- Responsive Design
- Modern UI
- Calm Color Palette

---
